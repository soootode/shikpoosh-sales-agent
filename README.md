# 🛍️ Shikpoosh Autonomous AI Sales Agent

یک دستیار هوشمند و خودمختار فروشگاهی توسعه‌یافته با **LangGraph**، **SQLite** و **Streamlit** با قابلیت مدیریت انبار و ثبت سفارش.

## ✨ قابلیت‌های کلیدی:
- 🔍 **استعلام خودکار انبار:** بررسی موجودی، سایز و قیمت کالاها از طریق Tool Calling.
- 📝 **ثبت سفارش در پایگاه‌داده:** ذخیره پایدار فاکتور مشتریان در دیتابیس SQLite.
- 📱 **اعتبارسنجی ورودی:** بررسی فرمت صحیح شماره تماس و اطلاعات پستی مشتری.
- 📊 **پنل مدیریت زنده:** نمایش وضعیت لحظه‌ای انبار و لیست سفارش‌های جدید.

## 🛠️ تکنولوژی‌ها:
`Python` • `LangGraph` • `LangChain` • `Groq API` • `SQLite` • `Streamlit`
